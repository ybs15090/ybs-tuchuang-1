# 个人图床 (Image Bed)

本仓库主要用于存放个人 Markdown 笔记、博客及文档所需的静态图片资源。

## 目录结构

图片统一放到img/ 目录下。

采用按月份建立子目录的方式进行归类存放，避免单目录下文件过多：
* `img/202610/`：存放 2026 年 10 月份上传的图片资源

## 图片命名规范

推荐统一采用 "日期 + 业务/主题前缀 + 序号(可选)" 的格式：
* **示例**：`20261024-stm32-01.png`
* **规则**：严格使用小写英文、数字、中划线，严禁使用中文、空格及特殊字符，确保链接在各平台上稳定解析。

## 访问与调用格式

### 1. 官方原始直链 (GitHub Raw)
格式：`https://raw.githubusercontent.com/用户名/仓库名/main/图片路径`

*优点*：无需配置加速服务  
*缺点*：国内部分网络环境访问可能较慢或出现加载失败

### 2. CDN 加速直链 (jsDelivr)
格式：`https://cdn.jsdelivr.net/gh/用户名/仓库名@main/图片路径`

*优点*：国内访问速度较快，加载稳定  
*缺点*：新上传图片可能存在短时间 CDN 缓存延迟

## 注意事项

* 本仓库仅用于个人低频图片托管，请勿上传违规或敏感内容。
* 单个仓库体积建议控制在 1GB 以内。
* 重要原始图片请务必在本地做好双重备份。
